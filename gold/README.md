# Gold scenarios

Gold scenarios are synthetic query contexts paired with an expected evaluator verdict and a written statutory justification. No scenario may contain a plate value, image, real location, name, or real agency query data.

The initial synthetic fixtures exercise evaluator semantics only. Each fixture can assert the expected verdict and, when useful, the exact deciding rule IDs. The conformance runner reports both values and leaves source selection to the caller.

Statute-authored scenarios may be added only after the corresponding ruleset completes independent review.
