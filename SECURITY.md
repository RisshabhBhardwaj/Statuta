# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose sensitive data, bypass a structural data-handling safeguard, or produce a permissive evaluation error.

Use GitHub's private vulnerability-reporting feature when it is enabled for this repository. Until then, contact the repository owner privately through their GitHub profile with a concise description, the affected version or commit, safe reproduction steps, and potential impact.

We will acknowledge reports promptly, investigate before disclosure, and coordinate a fix and public advisory where appropriate.

## Scope

`statuta` is pre-release. A defect that could cause a rule to be accepted without valid grounding, alter deterministic evaluation, coerce an unknown result into permission, or permit prohibited data fields is in scope.
