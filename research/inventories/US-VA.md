# Virginia provision inventory

**Source:** Va. Code Ann. § 2.2-5517. **Status:** Complete Phase 0 inventory; draft only.

| Provision | Disposition | Phase 0 record |
|---|---|---|
| (A) definitions | Context | System/audit-trail terms require a richer data-kind model. |
| (B) approval/technical requirements; (C) contracts | Coverage gap | Division approval, configuration, and contract facts are not v0.1 context. |
| (D) permitted uses/query restriction | Coverage gap | Reasonable suspicion, alert category, trafficking, and audit-entry facts are not fully expressible. |
| (E) 21-day system-data retention | Candidate `VA-RET-001` | Span-grounded in the candidate ruleset. |
| (E) exception and audit-trail retention | Coverage gap | Civil action, prosecution, and detailed terminal dates require new facts. |
| (F) sharing/sale restrictions | Coverage gap | Database target, discovery, subpoena, maintenance, and emergency purposes are not complete v0.1 facts. |
| (G)–(K) records, policy, reporting, posting | Obligation gap | Fulfilment tracking is explicitly outside v0.1. |
| (L) speech/lawful-activity restriction | Coverage gap | Protected-activity facts are intentionally absent. |
| (M) vehicle-stop requirements | Coverage gap | Independent reasonable suspicion and visual confirmation are unmodeled. |
| (N)–(O) misdemeanor/suppression | Out of scope | Remedies are recorded, not evaluated. |
| (P) exemptions; (Q) vendor notice; (R) awareness | Coverage gap/obligation gap | Actor-purpose, vendor, and public-awareness facts are outside v0.1. |
